# Uso

## Ejemplo de ejecución
```text
=== GESTOR DE TAREAS ===
1. Añadir tarea
2. Ver tareas
3. Eliminar tarea
4. Salir
Elige una opción: 1
Descripción: Estudiar Git
Tarea añadida.
```

## Opciones
| Opción | Acción |
|---|---|
| 1 | Añade una tarea nueva |
| 2 | Muestra todas las tareas |
| 3 | Elimina una tarea por su número |
| 4 | Sale del programa |

# Guardado de tareas
Las tareas se guardan automáticamente en el archivo `tareas.json` al salir del
programa y se cargan al iniciarlo. Este archivo no se sube al repositorio.
