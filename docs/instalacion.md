# Instalación

## Requisitos
- Python 3.8 o superior
- Git

## Descarga
```bash
git clone https://github.com/aporcar25/plantillas-gestor-tareas.git
cd plantillas-gestor-tareas
```

## Configuración
No necesita configuración adicional.

## Ejecución
```bash
python main.py | py main.py
```

## Comprobación
Si aparece el menú "GESTOR DE TAREAS", la instalación es correcta.
