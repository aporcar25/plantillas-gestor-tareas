# Gestor de tareas

Aplicación en Python para gestionar una lista de tareas.

## Requisitos
- Python 3.8 o superior
- Git

## Instalación
```bash
git clone https://github.com/aporcar25/plantillas-gestor-tareas.git
cd plantillas-gestor-tareas
```

## Ejecución
```bash
python main.py | py main.py
```

## Documentación
La documentación está en `docs/` y se genera con MkDocs:
```bash
python -m pip install mkdocs
mkdocs serve
```
